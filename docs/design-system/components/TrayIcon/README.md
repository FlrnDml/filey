The Filey mark: a flatbed scanner, outline only, 1.5px stroke. It is the app icon motif and the menu-bar icon.

- Ship the menu-bar icon as a macOS **template image** (black on transparent, 18px with @2x) so the system tints it for light, dark and wallpaper-tinted menu bars. Never colour it.
- **Idle:** the plain scanner. **Working:** a heavier scan line across the lid while a PDF is analyzed. **Needs attention:** a solid dot top-right when an import failed or the key is missing.
- While the popover is open the system highlights the item; the preview shows that with `accent-subtle`.
- Tagline for first-launch and the README: "Scan it. Filed."
