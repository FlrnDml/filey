Buttons trigger one action; use one primary per view.

- **Primary** (`accent` fill, `on-accent` text): the main action.
- **Secondary** (`border-control` outline, `text`): everything else.
- **Danger** (`danger` text, outline): destructive, always with a confirmation naming the thing.
- Height 36px, `radius-md`, `space-4` side padding, `label` type. The consumer provides the click handler and the icon, if any.
