The first-launch flow, three short steps in one small window. It opens once, when no settings exist yet.

1. **Key:** paste the OpenRouter key (model is optional and set later). Continue stays disabled until the key is present.
2. **Start at login:** a plain yes / not now question, applied immediately and stored in the settings.
3. **Menu bar:** explains that the window closes, where the icon is, and that there is no Dock icon. It also names the inbox and target folder Filey created (`Filey/Inbox` in iCloud Drive). If it could not be created (e.g. iCloud Drive is off), an error text points to Settings → Filing with an "Open Settings" button instead. The only primary button is "Got it".
- Windows are 300–480px wide with standard traffic lights. Step counter in `text-muted`, one `title` heading, one primary button per step.
- Inbox, target and folder rules start with sensible defaults (the `Filey` folder with its `Inbox` is created at the first launch), so this flow never asks about them; it only tells where they are.
