The Filing tab: where documents come from, where they go, and what they are called.

- **Folders** show their path in `mono` with a Choose… button (native folder picker). The target may not live inside the inbox.
- **Naming template** is a `mono` input; right below it a `surface` preview shows the result for a sample document, updating as you type.
- **Folder rules** are plain-language: a folder path and a sentence describing what belongs in it. The AI picks the best description, so write them like you would explain them to a person. An `Unsorted` fallback row is always present and cannot be removed.
- Saying "applies to the next import only" is part of the design: already filed documents are never touched.
- The consumer provides the settings, the sample document and the handlers.
